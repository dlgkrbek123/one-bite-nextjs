페이지 라우터 버전에서는 페이지 컴포넌트에서 아래의 항목을 정의하여 데이터페칭을 수행
- props를 페이지 컴포넌트에 전달 => props drilling
- 모두 클라이언트 컴포넌트였기떄문에 컴포넌트에서 fetch하면 양쪽에서 실행되므로
  별도의 함수의 도움을 받음

export default function getServerSideProps() {}
export default function getStaticProps() {}
export default function getStaticPaths() {}

------------------------------------------------------------------------

앱 라우터에서는 서버 컴포넌트가 있으니까 컴포넌트 함수를 async로 선언하고 await를 내부에 작성
각 서버 컴포넌트가 자기가 필요로 하는애를 각자 fetch해오면 되서 props drilling안해도 될지

------------------------------------------------------------------------

데이터 캐시
- fetch로 불러온 내용을 Next서버에 보관하는 기능 (axios나 이런애는 안된다이 )
- 두번쨰 인자로 제어
  - 'no-store' => 절대 캐싱안함 (기본값)
  - 'force-cache' => 무조건 캐싱함
  - { next: { revalidate: 10 } } => ISR과 유사하게 캐싱 
  - { next: { tags: ['a'] } } => 온디맨드 ISR과 유사

fetch(url, { cache: 'force-cache' })
