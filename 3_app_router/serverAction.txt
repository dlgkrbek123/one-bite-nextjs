revalidatePath()로 경로를 재검증
- 페이지 컴포넌트 리렌더링
- 서버에서만 호출가능 (서버 액션 / 서버 컴포넌트)
- 이 페이지에 포함된 모든 캐시까지 무효화 (풀라우트 캐시 + 데이터 캐시)
  - 즉시 삭제는 아니라 .html파일은 고대로임
  - 다음요청이 들어올때 동적으로 생성하여 html파일 바꿈

- 2번째 인수 생략시 페이지


revalidatePath('/book/[id]',"page"); // 모든 도서 상세 페이지(동적페이지) revalidate

revalidatePath('/(with-searchbar)',"layout"); // 특정 레이아웃을 갖는 모든 페이지를 revalidate
revalidatePath('/',"layout"); // 모든 페이지 재검증

revalidateTag('tag');
- fetch에서 tag를 지정가능
- 태그 기반 특정 데이터 캐시를 재검증
